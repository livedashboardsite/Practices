4. Images

img is an empty element. src = where the image is, alt = text shown if it fails. Give only width to keep the shape. An image inside a link is clickable.

<img src="images/photo.jpg" alt="Description" width="300">
<figure><img src="a.jpg" alt="x"><figcaption>Caption</figcaption></figure>
<a href="https://google.com"><img src="go.png" alt="Go"></a>

Paths: photo.jpg (same folder), images/photo.jpg (inside folder), ../photo.jpg (one folder up). Here the images are inline data so they work anywhere.

9. CSS basics

selector { property: value; }. Three ways to add CSS: inline, internal (style tag), external (link tag). Class starts with a dot, id with #.

Inline style: dark red bold.

Class selector .hl: yellow background.

Id selector #intro: larger and navy (shown inline here).

Descendant selector .card1 p: italic and boxed.

a:hover - hover over the link to see the pseudo-class in the nav bar above.

* { font-family: Arial, sans-serif; }   /* universal */
p { color: #333; }                      /* element */
.highlight { background: yellow; }      /* class */
#intro { color: navy; }                 /* id */
h1, a { color: darkgreen; }             /* group */
.card p { font-style: italic; }         /* descendant */
.card > p { ... }                       /* direct child */
a:hover { color: red; }                 /* pseudo-class */

Units: px fixed, % of parent, em relative to parent font, rem relative to html (16px), vw/vh of the window. Colours: name, #hex, rgb(), rgba() (last value is transparency).

10. CSS priority

Order: !important wins, then higher specificity (inline > id > class > element), then the rule written later. Score as (ids, classes, elements).

Para 1: blue - only the element rule applies.

Para 2: orange - class beats element; later .c2 beats earlier .c2.

Para 3: red - id beats class.

Para 4: brown - inline beats id.

Para 5: purple - !important beats all.

p { color: blue; }            /* (0,0,1) */
.msg { color: green; }        /* (0,1,0) */
#special { color: red; }      /* (1,0,0) */
.msg { color: orange; }       /* same score, written later: wins over green */
.imp { color: purple !important; }

.note (0,1,0) beats div div p (0,0,3): compare left to right, the first bigger number wins. Inherited: color, font-*, line-height, text-align, list-style. Not inherited: margin, padding, border, width, height, background.

11. Box model

Content, then padding, border, margin. Default total width = width + padding + border. With border-box, width already includes padding and border. Drag the sliders.

Box

.box { width: 200px; padding: 20px; border: 5px solid black; margin: 30px; }
/* content-box: 200+20+20+5+5 = 250px  |  border-box: 200px */
margin: 10px 20px;         /* top/bottom, left/right */
margin: 10px 20px 30px 40px; /* top right bottom left */
margin: 0 auto;            /* centre a block that has a width */
